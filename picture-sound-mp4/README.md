# picture-sound-mp4

Pick one picture and one sound file (wav or mp3) and get an MP4 as long as the sound. Saved in your home folder.

Run: `./picture-sound-mp4.sh` (or no window: `./picture-sound-mp4.sh PICTURE SOUND NAME`)

Needs: `yad`, `ffmpeg`, `vlc` (optional, to play the result). `slideshow.sh` must sit next to the script (included).
